# Saarthi – Backend

Saarthi Backend is the **server-side application** of the **Saarthi Bank Management System**, built using **Spring Boot**.  
It handles authentication, authorization, business logic, database operations, and secure communication with the frontend.

The backend exposes **RESTful APIs** secured with **JWT authentication** and integrates with a **MySQL database**.

---

## 🏗️ Project Overview

The Saarthi Backend is responsible for:
- User authentication & authorization
- Secure JWT-based login and registration
- Account management
- Transaction handling
- Chatbot request processing
- Data persistence using MySQL

This backend follows a **layered architecture** and best practices for scalable Spring Boot applications.

---

## 🛠️ Tech Stack
